# Portfolio Mouadh Jemai — version GitHub sans sous-dossiers

Votre dépôt contient les fichiers directement à la racine, et non dans les dossiers `assets/`, `data/` et `documents/`.

## Fichiers
- `index.html` : page principale.
- `styles.css` : apparence du site.
- `site.js` : chargement dynamique des sections.
- `portfolio.js` : profil, compétences, expériences, formations, projets et liens vers les rapports.
- `background-sky.png` : image du ciel en arrière-plan.
- `vignette-master.png`, `vignette-pfe.png` : aperçus des projets.
- `CV_Mouadh_Jemai.pdf`, `Master_Industrie_4_0.pdf`, `PFE_Systeme_Verification.pdf`, `Presentation_Master.pdf`, `Presentation_Master.pptx` : documents publics.

## Publier avec GitHub Pages
1. Ouvrez **Settings** du dépôt GitHub.
2. Allez dans **Pages**.
3. Sous **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez **main** et **/(root)**, puis cliquez sur **Save**.
5. Attendez l'apparition du lien vers le site. Vérifiez le CV, les rapports, les images et le lien LinkedIn.

## Modifier depuis un téléphone
Ouvrez votre dépôt depuis le navigateur GitHub sur iPhone ou Android, connectez-vous, puis :
- **Informations et liens** : ouvrez `portfolio.js`, cliquez sur **Edit** (crayon), modifiez les champs souhaités, puis **Commit changes**.
- **Documents et photos** : ajoutez la nouvelle version dans le dépôt. Gardez exactement les mêmes noms de fichiers, ou modifiez les chemins de `portfolio.js` en conséquence.
- **Mise en page** : modifiez `styles.css` en gardant l'image `background-sky.png` à la racine.

Il n'y a pas de page d'administration dans ce site. Les changements sont publiés après commit et déploiement GitHub Pages.

**Confidentialité :** Votre dépôt est public. N'ajoutez jamais de mots de passe, de jetons ou de documents privés dans les fichiers publics.
